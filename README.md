# ML-Assignment 1

Four classification models built with scikit-learn / XGBoost.

| # | File | Model | Task | Dataset |
|---|------------------|-----------------------|-------------------------|-------------------------------------------|
| 1 | `1_random_forest_classifier.py` | Random Forest | Malignant vs benign tumor | sklearn Breast Cancer (built-in) |
| 2 | `2_logistic_regression_diabetes.py` | Logistic Regression | Diabetes yes/no | Pima Indians Diabetes |
| 3 | `3_xgboost_titanic.py` | XGBoost | Titanic survival | Titanic dataset |
| 4 | `4_decision_tree_diabetes.py` | Decision Tree | Diabetes yes/no | Pima Indians Diabetes |
